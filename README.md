# DSS Ventas Walmart

Dashboard web (Sistema de Soporte a Decisiones) para analizar las ventas semanales de 45 tiendas Walmart entre febrero de 2010 y octubre de 2012.

**Sitio publicado:** https://USUARIO.github.io/dss-ventas-walmart/

## Fuente de datos
Walmart Sales Forecast / Walmart Dataset (Kaggle). Completa autor, liga y fecha de descarga.

## Qué incluye
- KPI: ventas totales, venta semanal promedio, tienda líder, impulso en semanas festivas
- Gráficas: línea (semanal/mensual), barras por tienda, festivas vs. no festivas, estacionalidad mensual, dispersión con variable externa, tabla de ranking
- Filtros: tienda, año y tipo de semana

## Tecnologías
HTML, CSS, JavaScript y Chart.js. Datos estáticos en `data/ventas.json` (procesado desde `data/Walmart_Sales.csv`).
